TASK 11 — SEVEN SNEAKER STORE (HTML + CSS ONLY)

Pages included:
1. index.html    — Landing page / hero / service statistics
2. product.html  — Product details and image gallery
3. cart.html     — Shopping cart, coupon and order total
4. payment.html  — Checkout and payment form layout
5. css/style.css — Shared responsive styling

How to run:
- Extract this ZIP.
- Open the extracted folder in VS Code.
- Open index.html in your browser (or use Live Server).
- Use the navbar and page links to move between all four pages.

Important:
- This is a CSS-focused static mini project. No JavaScript is used.
- Cart quantities, coupon application, payment methods and payment submission are visual UI only; no backend or real payment is connected.
- Product photos and Google Fonts load from the internet, so an internet connection is needed for those assets.
